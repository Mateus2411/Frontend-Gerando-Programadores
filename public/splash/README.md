# Splash Screens para iOS

Para que o PWA tenha splash screens no iOS (Safari), você precisa gerar as seguintes imagens e colocá-las nesta pasta:

## Imagens necessárias:

1. **splash-iphone-se.png** - 640x1136px (iPhone SE 1ª geração)
2. **splash-iphone-12.png** - 1170x2532px (iPhone 12/13/14)
3. **splash-iphone-14pro.png** - 1179x2556px (iPhone 14 Pro/15 Pro)
4. **splash-ipad-pro.png** - 2048x2732px (iPad Pro 12.9")

## Especificações das imagens:
- Fundo: #181818 (ou #080f1c, conforme seu tema)
- Logo centralizado: if-logo-s-fundo.png (com padding de 20% nas bordas)
- Formato: PNG com transparência
- DPI: 3x para iPhones modernos, 2x para iPads

## Como gerar:
Você pode usar ferramentas como:
- [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator)
- [Splash Screen Generator](https://appsco.pe/developer/splash-screens)

Ou criar manualmente no Figma/Photoshop com as dimensões acima.
